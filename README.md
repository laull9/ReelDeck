# ReelDeck

> Pick a folder. Shuffle. Swipe.

本地视频随机播放器。选一个文件夹，递归扫描视频，TikTok 式随机刷。

当前第一版支持：

- macOS、Windows、Android 目录授权（外置盘重新连接后可重新解析）
- 递归扫描、单轮无重复随机队列和会话恢复
- media_kit 播放、预加载下一条、播放/暂停、进度拖动、适配模式、静音、倍速和全屏
- 收藏、隐藏视频、隐藏目录、收藏 Feed 和目录 Feed
- 播放位置、播放次数、设置、收藏与隐藏规则的本地 SQLite 持久化
- 目录断开、文件损坏和无可播放内容时的重试、跳过与重新授权入口

使用：启动应用后选择视频目录。桌面端可以使用 `J/K` 或方向键切换，空格播放/暂停，`F` 收藏，`H` 隐藏视频，`Shift+H` 隐藏目录，`R` 重新随机，`M` 静音，`Enter` 全屏；移动端上下滑动切换，双击收藏，长按临时 2 倍速。

目标平台: macOS / Windows / Android
