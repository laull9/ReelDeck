# ReelDeck v0.4.0

本版优化播放与切换体验，降低切片延迟，并提供完整的多语言国际化支持。

## 播放与性能

- **双向环形预加载**：采用 3 播放器缓冲池（当前、前一个、后一个），支持前后双向预载与就绪复用，切片无黑屏。
- **解码优化**：增加硬件解码与兼容模式配置（Auto、Auto-Safe、纯软解），优化 probe 探测与首帧零偏移响应。
- **手势与状态修复**：修复无视频时提示引导界面被误滑的问题；重构切换时序，消除切片时的旧画面闪烁与回弹。
- **界面精简**：移除初始界面辅助冗余文案，保持界面简洁。

## 国际化

- **应用多语言**：跟随系统语言自动匹配，支持在设置中手动切换（英语、简体中文、日语、西班牙语、法语）。
- **多语言文档**：提供 5 种语言的 README 文档与顶部互跳导航。

## 验证范围

- 静态分析 `flutter analyze` 零告警。
- 全部 67 项 Flutter 测试、打包脚本单元测试和图标检查全部通过。
