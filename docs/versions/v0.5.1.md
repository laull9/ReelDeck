# ReelDeck v0.5.1

修复视频播放到中途坏点时的进度停滞、错误恢复，以及滑动切换后黑屏仍播放旧声音的问题。构建号从 7 增至 8。

## 播放与切换

- 原生属性查询移到后台 isolate，属性设置使用异步命令，避免解码压力下阻塞界面线程。
- 可恢复的音视频坏帧交给解码器继续处理，持续停滞才停止旧播放并跳过；错误恢复与完成事件按媒体身份去重。
- 切换前先停止旧视频，再等待预加载和路径解析；加载与重试控件固定在屏幕上。
- 新视频启动后立即发布画面与进度，播放记录写盘不会冻结进度条。
- 备用播放器的解码设置与打开文件串行执行，避免交接后的旧预加载修改前台播放器。
- 播放中的定位按实际倍速容许进度自然前移，减少误报超时。

## 验证

- 109 项 Flutter 测试与静态分析通过。
- macOS 打包 libmpv 通过双播放器 4K60 H.264、10-bit HEVC 软解与定位测试，以及截断、损坏帧、无效容器后的恢复测试。
- 专项样本仅损坏第 3–3.5 秒的 15 个视频包；实际解码报错后，第 6–7 秒继续输出 30 帧，暂停和打开下一条通过。
- 本机 Xcode 缺少 CoreSimulator.framework，原生窗口构建未完成；Windows、Linux、Android 实机播放验证待执行。

复现步骤与验证范围见 [播放维护文档](../playback.md)。
