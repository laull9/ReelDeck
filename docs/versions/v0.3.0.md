# ReelDeck v0.3.0

本版完成 DESIGN 第二、第三版功能，并提供 Windows、Linux、macOS 的 x64 / ARM64 包和 Android ARM64 / ARMv7 APK。

## 播放与浏览

- 支持收藏、多来源和子目录播放范围，增加智能随机、最新优先与最旧优先。
- 可选图片 / GIF 播放、停留时间、暂停和计时进度保存。
- 桌面端可在文件管理器定位媒体，并在确认后移入系统回收站。
- 补齐精简显示、动画、双击收藏、键盘快捷键、预加载和外置盘缓冲设置。
- 保存队列、播放进度与最近 100 条错误；修复进度并发写入和 Android 单解码器切换。
- 修复滑到新视频后的跳动：旧视频先离场，新视频固定在零偏移，后台预加载完成后不再触发延迟位移动画。
- 统一项目图标、平台图标和 README。智能随机覆盖 20,000 项队列测试。

## 安装包

Windows 与 macOS 提供双架构 ZIP；Linux 提供双架构 deb、rpm；Android 提供 ARM64、ARMv7 APK，最低 Android 7.0。下载后可使用 `SHA256SUMS` 检查文件。

Android 从本版开始使用固定发布密钥。安装过旧测试签名 APK 的设备须先卸载旧包，卸载会清除应用内记录；媒体文件保持不变。macOS 包采用本地签名，尚未做 Apple 公证。

本地 Flutter 分析、66 项 Flutter 测试、5 项打包脚本测试和 27 个图标文件检查通过。工作流检查各架构的原生库、打包内容和签名；Linux 还检查 deb 安装与 Xvfb 启动。真实设备的硬件解码、外置盘重挂载和 Android SAF 重启验收见 [TODO](https://github.com/laull9/ReelDeck/blob/v0.3.0/TODO.md)。
