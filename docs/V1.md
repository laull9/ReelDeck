# 第一版实施与验收

沿用 DESIGN.md 的 MVP 范围：选目录、递归扫描、随机播放、单轮不重复、滑动与键盘控制、收藏与隐藏、目录授权、队列恢复和设置。

SourceManager 管理目录授权与索引，LibraryStore 负责 SQLite 读写。媒体身份使用 sourceId 与相对路径，扫描更新保留已有 ID；扫描失败保留原索引。FeedController 串行处理播放切换，PlayerPool 在桌面预加载下一条，Android 只保持当前播放器。界面订阅播放器状态，不生成模拟路径。

macOS 使用 security-scoped bookmark；Android 使用 SAF tree URI 和持久授权；Windows 保存卷 GUID 与卷内路径。授权失效时保留索引，允许重新选择目录并保留 Source ID。任何操作都不删除原视频。

会话只保留最新一条，设置保存在应用支持目录。扫描不计算哈希、不生成缩略图；完整扫描成功后才清理消失文件的索引和状态。媒体索引随实际文件数增长，移除来源时清理关联状态。

验收包括数据库重启与重扫身份、过滤和队列恢复、播放器事件与切换、静态分析和本机 release 构建。跨平台构建及设备验收单独记录，不把本机结果视为其他平台通过。
